# Israt Anjum Taspia — Personal Portfolio 💜

A sleek, responsive, and neon-cyberpunk aesthetic portfolio website designed for **Israt Anjum Taspia** (Frontend Developer & CSE Undergrad).

Inspired by modern UI design systems and featuring high-performance vanilla HTML, CSS, and JavaScript.

---

## ✨ Features

- **Neon Cyber Aesthetic:** Custom curated purple color palette inspired by deep royal aesthetics, glowing borders, and backdrop blurs.
- **Dynamic Starfield Canvas:** Custom particle background engine with smooth physics.
- **Bilingual Support (EN / BN):** Seamless one-click English ↔ বাংলা localization switcher.
- **Interactive Avatar Switcher:** Quick-toggle between real portrait and GitHub profile avatar.
- **Sound Effects (Web Audio API):** Subtle UI micro-interactions synthesized entirely in-browser with zero external audio assets.
- **Showcase Sections:**
  - **Hello / Hero:** High-impact typography with dynamic role typewriter.
  - **About Me:** Clean introduction and key technical pillars.
  - **Skills Grid:** Vector SVG badges for modern web & systems technologies (React, Tailwind, JavaScript, C++, Python, Git, Figma, etc.).
  - **Projects Showcase:** Highlighted collaborative and individual works (*ChobiDeh Vol. 1*, *KoyJabo Transit Navigator*, *Map Estate*, *Behance Design*).
  - **Interactive Footer:** GitHub repository star prompt and smooth back-to-top navigation.

## 💻 Local Development

Clone the repository and serve locally:

```bash
# Clone the repository
git clone https://github.com/taspiaisratanjum77-glitch/taspia-portfolio.git

# Navigate into project directory
cd taspia-portfolio

# Start a local static server (Python)
python3 -m http.server 8088

# Open in browser
open http://localhost:8088
```
