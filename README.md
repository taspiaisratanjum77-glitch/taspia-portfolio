## 📖 About The Project

Welcome to the personal portfolio of **Israt Anjum Taspia**, Computer Science & Engineering student, Frontend Developer, and Competitive Programmer.

Built with an obsession for visual excellence, this portfolio features a curated dark-purple and neon glow color scheme, smooth micro-interactions, synthesized in-browser audio cues, dynamic starfield physics, and full bilingual localization (English ↔ বাংলা).

---

## ✨ Key Highlights

- 🎨 **Aesthetic UI:** Inspired by deep royal purple gradients, glassmorphism cards, and vivid neon glows.
- 🌌 **Starfield Physics Engine:** Zero-dependency HTML5 Canvas rendering floating star particles that react smoothly.
- 🌐 **Instant Bilingual Toggle:** One-click language switch between English and বাংলা with persistent smooth transitions.
- 🎵 **Web Audio Synthesizer:** Real-time audio micro-feedback synthesized in-browser with procedural oscillators (Zero external MP3/WAV assets).
- 🔄 **Interactive Avatar Toggle:** Switch seamlessly between real portrait photography and partner GitHub profile avatar with audio feedback.
- 🚀 **Zero Heavy Framework Overhead:** 100% lightweight Vanilla HTML5, modern CSS3 (Flexbox/Grid), and ES6+ JavaScript for blazing fast 100/100 Lighthouse performance.

## 🚀 Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/taspiaisratanjum77-glitch/taspia-portfolio.git

# 2. Enter directory
cd taspia-portfolio

# 3. Serve with any static HTTP server (e.g. Python)
python3 -m http.server 8088

# 4. Open in your browser
open http://localhost:8088
```
